# 使用拟定API

在Visual Studio Code，我们很重视扩展API兼容性。我们尽力避免破坏性API修改，扩展作者可以期望发布的扩展继续运作。然而，这给我们带来了很大的限制：一旦我们引入了一个API，我们就再也不能轻易修改它。

拟定API帮我们解决了这个问题。拟定API是一系列不稳定的API，在VS Code中实现，但不作为稳定API暴露。他们**可能被修改，仅在内部分发版可用**，并且**不应在发布的扩展中使用**。然而，作者可以在本地开发测试这些API，并提供反馈给VS Code团队来迭代API。最终，拟定API会进入稳定API，并对所有扩展可用。

## 使用拟定API
这些是在本地扩展开发中测试拟定API的步骤：

- 使用VS Code的[内部](https://code.visualstudio.com/insiders)发布版。
- 到`package.json`中，添加`"enableApiProposals": ["proposalName"]`。
- 拷贝相关的[vscode.proposed.<proposalName>.d.ts](https://github.com/microsoft/vscode/blob/main/src/vscode-dts)文件到项目源位置。

[@vscode/dts](https://github.com/microsoft/vscode-dts) CLI工具让您快速为扩展开发下载最新的`vscode.proposed.<proposalName>.d.ts`。它通过`package.json`文件列出的提案下载定义文件。

```bash
> npx @vscode/dts dev
Downloading vscode.proposed.languageStatus.d.ts
To:   /Users/Me/Code/MyExtension/vscode.proposed.languageStatus.d.ts
From: https://raw.githubusercontent.com/microsoft/vscode/main/src/vscode-dts/vscode.proposed.languageStatus.d.ts
Read more about proposed API at: https://code.visualstudio.com/api/advanced-topics/using-proposed-api
```

这是使用拟定API的案例：[proposed-api-sample](https://github.com/microsoft/vscode-extension-samples/tree/main/proposed-api-sample)

## 拟定API的不兼容性
在主分支，`vscode.proposed.<proposalName>.d.ts`永远兼容`vscode.d.ts`。然而，当您添加`vscode.proposed.<proposalName>.d.ts`到使用`@type/vscode`的项目中，最新的`vscode.proposed.<proposalName>.d.ts`也许不会兼容`@types/vscode`的版本。

您可以通过下面两种途径解决此问题：

- 移除对`@type/vscode`的依赖，并使用`npx @vscode/dts main`从`microsoft/vscode`主分支下载`vscode.d.ts`。
- 使用`@type/vscode@<version>`和`npx @vscode/dts dev <version>`从`microsoft/vscode`旧分支下载`vscode.proposed.<proposalName>.d.ts`。然而，请小心最新版本VS Code内部版对API的修改。

## 分享使用拟定API的扩展
尽管您不应该在市场发布使用拟定API的扩展，但是通过打包并分享扩展，您也可以与同伴分享扩展。

要打包扩展，您可以运行`vsce package`创建扩展的VSIX文件。您可以随后分享VSIX文件给其他人，让其在VS Code中安装扩展。

要从VSIX文件安装扩展，跳转到扩展视图，选择...省略号**查看更多操作**按钮，选择**从VSIX安装**。

选择下方短视频展示的**从VSIX安装**菜单项。

![](https://code.visualstudio.com/assets/api/advanced-topics/proposed-api/install-from-vsix.gif)

对于使用拟定API的扩展，启用扩展有额外的步骤。在从VSIX安装扩展后，您需要退出并在项目文件夹中使用命令行`code-insiders . --enable-proposed-api=<YOUR-EXTENSION-ID>`重启VS Code内部版。

如果您希望设置来让您使用拟定API的扩展在每次VS Code内部版启动时永远可用，可以运行**偏好：配置运行时参数**命令，编辑`.vscode-insiders/argv.json`文件设置一系列启用扩展。

```json
{
    ...
    "enable-proposed-api": ["<YOUR-EXTENSION-ID>"]
}
```
