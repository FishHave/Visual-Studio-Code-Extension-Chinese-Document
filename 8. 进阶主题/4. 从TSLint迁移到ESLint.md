# 从TSLint迁移道ESLint
[TSLint](https://palantir.github.io/tslint/)再过去曾是推荐的代码检查工具，但现在已经被弃用，[ESLint](https://eslint.org/)正在取代它的地位。本文帮助您从TSLint迁移道ESLint。

## ESLint：安装
您需要安装ESLint。ESLint并不原生支持TypeScript，所以您也需要安装eslint-typescript-support：
```bash
npm install --save-dev eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
```

或者如果您正在使用yarn作为包管理器：
```bash
yarn add eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin --dev
```

上方命令添加Eslint、让ESlint理解TypeScript的解析器以及一些TypeScript独有规则。

现在，为了让迁移简单些，运行[tslint-to-eslint-config](https://github.com/typescript-eslint/tslint-to-eslint-config)工具。这个工具将读取您的TSLint配置，并创建最接近的ESLint配置。
```bash
npx tslint-to-eslint-config
```

命令[下载并执行](https://www.npmjs.com/package/npx)此工具实施迁移。如要使用更多选项，检查工具的[使用指南](https://github.com/typescript-eslint/tslint-to-eslint-config#usage)。

执行后应该产生了新的`.eslintrc.js`文件、日志文件（`tslint-to-eslint-config.log`），并可能更改其他文件，比如`.vscode/settings.json`。仔细检查修改，尤其是对已有文件的修改，并检查日志文件。

## ESLint：配置
`eslintrc.js`文件通常足够开始，但可能`parserOptions.project`属性仍然设置为`tsconfig.json`。那意味着ESLint规则可以使用语义信息，比如说，变量为字符串还是数值数组？这项配置启用了一些强大的功能，但意味着ESLint花费更久进行计算。对于扩展的默认规则不需要语义信息，除非您已经添加了这么做的规则，我们推荐您移除`parserOptions.project`属性。

## ESLint：运行

现在您可以运行ESLint，但在此之前，我们建议您禁用TSLint。如此，打开扩展视图，选择TSLint扩展上下文菜单中的**禁用**。

现在是代码检查时间！使用命令：`eslint -c .eslintrc.js --ext .ts <mySrcFolder>`（注意`--ext .ts`选项告知ESLint关注T一盆Script文件）。我们推荐将命令放在`package.json`文件的`scripts`段中，像这样：
```json
"lint": "eslint -c .eslintrc.js --ext .ts <mySrcFolder>"
```

要在Visual Studio Code中迁移ESlint，做下面的事情：
- 安装[ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)扩展。
- 通过**任务：配置任务**命令创建任务，选择**npm: lint**。
- 在返回的`tasks.json`文件，配置问题配对器为`$eslint-stylish`。

**提示**：ESLint有时在做事情方面“更加正确”，所以您可能看到您之前没有见过的警告，例如指出缺失的分号。尝试`--fix`选项让ESLint为您解决这些杂事。

## TSLint：移除
恭喜。您现在应该已经启动了能运行的ESLint，现在是时候打扫屋子了。

TSLint的移除取决于项目，但通常是下面的步骤：

- 更新`.vscode/extensions.json`，推荐ESLint扩展而不是TSLint：

```json
"recommendations": [
    "dbeumer.vscode-eslint"
]
```

- 移除`.tslint.json`文件。
- 在`package.json`文件中移除对`tslint`的依赖。
- 使用`npm uninstall tslint`卸载TSLint。
