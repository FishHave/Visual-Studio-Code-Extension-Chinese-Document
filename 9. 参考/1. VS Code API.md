# VS Code API
**VS Code API**指的是您可以在Visual Studio Code扩展中调用的JavaScriptAPI集合。本页面列出了对扩展作者开放的所有VS Code API。

## API命名空间与类
此列表编译自VS Code仓库的[vscode.d.ts](https://github.com/microsoft/vscode/blob/main/src/vscode-dts/vscode.d.ts)文件。

### 函数
<details>
<summary><b>getAccounts(providerId: string): Thenable&lt;readonly AuthenticationSessionAccountInformation[]&gt;</b></summary>

获取用户到某个提供者的所有账户。与getSession搭配使用以便获取某个账户的验证会话。

当前仅有两个内建扩展提供的验证提供者贡献给了编辑器，实现了GitHub和Microsoft验证：它们的providerId为 'github'和'microsoft'。

注意：获取账户并不代表您的扩展可以访问账户或其验证会话。您可以调用getSession验证账户的访问。

| 形参 | 简介 |
| - | - |
| providerId: string | 提供者使用的ID |
| **返回** | **简介** |
| Thenable<readonly AuthenticationSessionAccountInformation[]> | 一个thenable对象，指向验证账户的仅读数组。 |

</details>


<details>
<summary><b>getSession(providerId: string, scopeListOrRequest: readonly string[] | AuthenticationWwwAuthenticateRequest, options: AuthenticationGetSessionOptions & {createIfNone: true | AuthenticationGetSessionPresentationOptions}): Thenable&lt;AuthenticationSession&gt;</b></summary>

获取用户匹配期望限制域或满足WWW验证请求的验证会话。如果提供者的providerId未注册，或用户不许可分享验证信息给扩展，则拒绝。如果在同一限制域内有多个会话，用户将展示快速选单选取它们希望使用的账户

内建验证提供者包括：

- 'github' - 来自GitHub.com
- 'microsoft' - 来自个人和组织Microsoft账户
- （较少见）'github-enterprise' - 来自其他GitHub主机，GHE.com、GitHub Enterprise Server
- （较少见）'microsoft-sovereign-cloud' - 来自其他Microsoft云

| 形参 | 简介 |
| - | - |
| providerId: string | 提供者使用的ID |
| scopeListOrRequest: readonly string[] | AuthenticationWwwAuthenticateRequest | 一个限制域列表，包含许可请求或WWW验证请求。这些依据验证提供者而不同 |
| options: AuthenticationGetSessionOptions & {createIfNone: true | AuthenticationGetSessionPresentationOptions} |  使用的AuthenticationGetSessionOptions |
| **返回** | **简介** |
| Thenable<AuthenticationSession> | thenable对象，指向验证会话 |
</details>
